# Employee Management System

A Spring Boot backend application for managing employees and departments using REST APIs.  
The project follows a layered architecture using Controllers, Services, Repositories, DTOs, Custom Response Structures, and Global Exception Handling.

## Features

- Employee CRUD Operations
- Department CRUD Operations
- RESTful API Development
- Layered Architecture
- DTO Implementation
- Custom API Response Structures
- Global Exception Handling
- Spring Data JPA Integration
- MySQL Database Support

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Project Structure

- Controller Layer
- Service Layer
- Repository Layer
- Entity Layer
- DTO Layer
- Structures Layer (Custom API Responses)
- Global Exception Handling
